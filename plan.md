Project Plan
1. Project Plan
Goals: Analyze the length, width, and depth of the diamonds dataset, generate LaTeX tables containing descriptive statistics, and output a PDF report.

Requirements: An R environment is required, with dependencies on the tidyverse, knitr, and kableExtra packages.

Steps: 1. Clean the data (remove outliers where x, y, and z are 0). 2. Calculate statistics grouped by cut. 3. Render tables using kbl(). 4. Compile into a PDF.

2. Repository Setup and Maintenance
Branching: Use the main branch as the stable version and the dev branch for daily development.

Issue Tracking: Use GitHub Issues to record code bugs and future improvement points.

Commit Convention: Each commit must include a clear description (e.g., "Fix table formatting").
