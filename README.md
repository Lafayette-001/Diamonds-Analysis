# Diamonds-Analysis
Diamonds Descriptive Statistics Analysis
1. Repository/Project Content
This project uses R to perform exploratory data analysis on the diamonds dataset. It calculates descriptive statistics (e.g., mean, median, percentiles) for length (x), width (y), and depth (z) by cut quality (Cut).

2. Data Source
The data comes from the built-in diamonds dataset in the R ggplot2 package.
